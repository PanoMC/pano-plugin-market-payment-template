Example Pay for Pano Market

Example Pay lets your store take card and wallet payments. This plugin adds Example Pay as a payment method to Pano Market, which must be installed and running: it is a required dependency of this plugin.

What it supports

  • Payments in EUR, USD, GBP, TRY and JPY, paid on the Example Pay hosted checkout page.
  • Full and partial refunds from the Pano panel.
  • Automatic payment status checks when the buyer returns to your store.
  • Test mode against the Example Pay sandbox.
  • One-time payments only; recurring payments are not offered.

Verification level

Unverified: this plugin has not been tested against a live or sandbox Example Pay account. Its signature handling was checked only with test values computed from the documented algorithm.

Setup

  1. Install Pano Market, then this plugin, and open Market, Payment methods, Example Pay in the panel.
  2. Paste the API key and the webhook secret from the developer section of your Example Pay dashboard.
  3. Copy the webhook URL shown in the form into your Example Pay dashboard as a webhook endpoint and select the events payment.updated and refund.updated.
  4. Press “Test connection”, then enable the method.
